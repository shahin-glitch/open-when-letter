# Open When Letters

A small, responsive website for sharing “open when” letters. Choose an envelope to reveal a personal message, with an animated letter-opening effect.

## Features

- Six letters: miss me, having a bad day, needing a hug, unable to sleep, needing reassurance, and thinking of me.
- Responsive envelope selection page.
- Animated letter reveal and a link back to the envelopes.
- Custom background and envelope artwork.

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select an envelope to read its letter.

For a local web server, you can also use the VS Code **Live Server** extension and open `index.html` with it.

## Project files

```text
.
├── index.html       # Envelope selection page
├── letter.html      # Letter display page
├── script.js        # Letter messages and page behavior
├── styles.css       # Layout, styling, and responsive rules
└── images/          # Background, envelope, and letter artwork
```

The site loads its decorative fonts from Google Fonts, so those fonts require an internet connection. The rest of the site is served from the files in this repository.
